Book Web Scraper

A Python web scraper that extracts book details from an online bookstore and stores data in CSV format.

Features
- Extracts book names
- Extracts prices
- Extracts ratings
- Saves data to CSV

Technologies Used
- Python
- BeautifulSoup
- Requests
