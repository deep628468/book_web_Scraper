Book Web Scraper

A Python web scraper that extracts book details from an online bookstore and stores data in CSV format.

Features
- Extracts book names
- Extracts prices
- Extracts ratings
- Extracts publisher details
- Saves data to CSV

Technologies Used
- Python
- BeautifulSoup
- Requests
- CSV

   How to Run
1. Install Python
2. Install required libraries:
   pip install beautifulsoup4 requests lxml

3. Run:
   python book_scraper.py
